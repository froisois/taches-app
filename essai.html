Essai sur téléphone

Page d’essai sans aucune donnée : rien n’est envoyé nulle part, le fichier est lu sur le téléphone. Fais les trois essais, puis « Copier le rapport » et colle-le à Claude.

1. Lire un fichier du OneDrive pro

Touche le bouton, choisis OneDrive dans le menu, puis ton taches.md (ou n’importe quel fichier texte de ton OneDrive pro).




2. Le même, avec un filtre « texte »


Pour savoir si Android grise les fichiers .md quand on filtre. Si le fichier est grisé ou absent, dis-le simplement.






3. Préparer un e-mail


L’adresse n’est gardée que dans ce téléphone.








5. Écrire dans OneDrive par le partage


Le bouton crée un petit fichier texte et ouvre le menu Partager d’Android. Choisis OneDrive, ton compte pro, puis le dossier où tu as mis taches.md, et valide l’envoi.


Ensuite, vérifie dans l’appli OneDrive (ou sur le PC) que le fichier a-trier-essai.txt est bien arrivé dans ce dossier.
