# Icônes de rechange

Pour reprendre une de ces icônes : copier le fichier dans `app/src/main/res/drawable/ic_avant.xml`
et mettre la couleur de fond correspondante dans `app/src/main/res/values/colors.xml` (`icone_fond`).

| Fichier | Fond (`icone_fond`) | Description |
|---|---|---|
| `ic_avant_A_verte_initiale.xml` | `#2F6F5E` | première icône : trois barres blanches, coche verte (jusqu’à la version 1.22) |
| `ic_avant_F_verte_cercles.xml` | `#2F6F5E` | piste F : fond vert, barres blanches, cercles des cartes, recentrée |
| `ic_avant_G4_verte.xml` | `#2F6F5E` | piste G4 : fond vert, cartes blanches — note, tâche à faire, tâche faite pâlie (version 1.25) |
| `ic_avant_D_creme.xml` | `#FBFAF7` | piste D : fond crème, une note ocre, une urgente rouge, une tâche cochée (version 1.24 ; trop peu contrastée sur l'écran d'accueil) |
| `ic_avant_I_rouge_adouci.xml` | `#FFFFFF` | icône inversée, carte « à faire » rouge adouci `#DB6B63` |
| `ic_avant_I_rouge_pale.xml` | `#FFFFFF` | icône inversée, carte « à faire » rouge pâle `#E9928B` |
| `ic_avant_I_rouge_tres_pale.xml` | `#FFFFFF` | icône inversée, carte « à faire » rose très pâle `#F6D3CF`, cercle et trait rouges `#C4524A` (coup de cœur de François) |
| `ic_avant_I_cases_rondes.xml` | `#FFFFFF` | icône inversée à cases rondes (disque blanc cerclé, disque vert coché), versions 1.27 à 1.37 |

Icône en service depuis la version 1.38 : **G4 inversée, cases carrées** (fond blanc `#FFFFFF`, cartes vert sapin ; tâche à faire : case blanche arrondie cerclée de vert sombre `#1E4A3E` ; tâche faite : case vert sapin, coche blanche), comme les cases de l'appli. Fond blanc choisi pour mieux s'accorder aux autres icônes de l'écran d'accueil. La version 1.26 (anneau blanc, disque coché blanc) est la base des trois variantes rouges ci-dessus.
